# Public operations project conventions

Read HANDOFF.md, docs/migration.md and the relevant experiment report before continuing. This repository contains public RCAEval studies only. Use Northstar Telecom if a fictional operator is needed; do not add real operator names or internal network data.

Compare Jev, local fitted ML and transparent baselines on the same evidence. Do not introduce another model provider, download language-model weights or execute network changes without a new request. Credentials stay server-side in ignored .env/environment variables, out of Git, logs and exports. The app remains read-only and loopback-only.

Keep inputs separate from published answer keys. Source directory names and case-index answers must never enter requests. Known injection time is a supplied experimental condition, not incident detection. Preserve correlated service/fault repetitions within each split. Missing values are not zeros or successful measurements.

The two completed public studies and all imported checkpoints are frozen. provenance/source contains original source bytes, not executable application dependencies. provenance/migration.json fingerprints both archived dependencies and the extracted active baseline. Do not modify those files or the active inference modules after recording the standalone verification. Add separate modules and protocols for new experiments; keep old verification working.

Never rerun a completed historical protocol or retune against its evaluation. Any new exact-request replay needs its own budget and frozen protocol, and measures variability on inspected cases rather than new held-out performance. Keep the 36 Sock Shop reserve cases undownloaded until a confirmation protocol is frozen. Preserve frozen ML training evidence and all 0.50 and 0.60 display boundaries.

Do not fabricate missing predictions or hide regressions behind aggregate gains. Verify completed evaluation and its committed boundary before exposing held-out cases or showing thresholds. All recommendations need analyst review; small benchmark results do not establish operational reliability or telecom readiness.

Before publication, run the Python unit suite, both pack validators, scripts.verify_evidence with the restored bundle and syntax checks for all browser scripts. Review the app and formatted report links. Update HANDOFF.md and docs/verification.md when state changes. Run files remain ignored and are shared as versioned release assets; never replace a released bundle with different evidence.

Write plain, concise prose. Use first person for authorship and choices; let models, data and results lead descriptions of behavior. Avoid repeated I used/I trained/I will openings, em dashes, fluff and unsupported causal claims.

The completed repeatability protocol and its new inference/scoring modules are frozen too. Do not rerun it or edit its fingerprinted source. Its research gate failed; the Sock Shop reserve remains sealed. Add new diagnostic modules for further transformations.

Fresh Train Ticket development, the one-call context probe and the three-round temporal comparison are frozen and complete. Preserve their preparation/source fingerprints and recorded results. The user selected fewer wrong leads on 2026-10-04. The new public-selective protocol may open calibration only after its plan is committed, and evaluation only after a verified committed calibration boundary. Use scripts.verify_public_diagnostics for all later evidence; the original evidence verifier still checks public-study-v1 independently.
