# Literal claim definitions reduce wrong displays through withholding

The new literal-claim comparison is complete: 36 valid once-only Jev replies on six inspected claims, two instruction versions and three rounds. Both versions display twelve judgments correctly. The literal version displays no wrong judgment and withholds six; the legacy version displays two wrong judgments and withholds four.

The candidate fails the frozen coverage requirement. It displays four of six correctly per round rather than five, and neither remaining error claim becomes a correct displayed answer. It provides a useful withholding result, not improved correct-answer coverage or operational validation.

## The new task definition

The user selected judgment of the claim as written. A claim that a report confirms a cause differs from a claim that the cause itself is known. When the report explicitly says investigation is ongoing, the assertion that this report confirms the cause is contradicted. Mere absence of relevant information remains not established.

This changes one reference: the April 26 confirmation claim becomes contradicted. Its evidence spans, claim wording and incident selection stay unchanged. The five other references remain byte-identical. Historical studies retain the original not-established reference and every recorded score.

These six literal references contain supported and contradicted examples, but no not-established example. This diagnostic cannot establish performance across all three classes.

## What Jev receives

Both fresh arms receive byte-identical state: the original claim, an explicit selected incident header, the report introduction and that incident’s complete blocks. Only question instructions and verdict criteria change. The legacy control reproduces the completed selected-section request exactly, with fresh replies.

The literal criteria refer to the exact proposition, including subject, time, quantifiers and certainty. They distinguish an explicitly incompatible statement from missing information. Added instructions tell Jev not to substitute a weaker proposition or a question about the underlying event. No reference label, evidence span or claim ID enters the state.

The plan, new reference version and producers were committed first; a separate exact 36-call protocol was committed before inference. Inputs rotate across three rounds. The model stays Jev 1.13.0, and the display boundary stays 0.70. No call was retried or repaired, and no new report or telemetry recording opened.

## A reference change is not a model gain

Reclassifying the eighteen earlier selected-section replies against the new literal references would give twelve correct displays, three wrong and three withheld, without making a call or changing an answer. The three confirmation replies account for that difference from the historical nine correct displays.

That is a change in the task’s reference definition. The fresh paired comparison above measures the instruction change under one fixed new task. Keeping the two effects separate prevents an apparent accuracy gain caused only by changing what counts as correct.
