# Resolve a subject before reading later text

## Purpose

I will test whether later text distracts Jev from resolving a claim's subject. The comparison keeps one subject question per call in both inputs. The full-note control includes the original note; the prefix input ends exactly at the queried sentence.

The earlier direct-subject batch improved displayed coverage but retained a redis pronoun error. Its results remain historical context. Fresh controls are necessary because this experiment also changes grouping from six subject questions to one.

## Frozen setup

The same 27 inspected controlled notes supply six confirmed claims each, with plain, negated and boundary wording on nine recordings. Both inputs retain the literal question, answer options, complete observed service inventory and model profile. Only the note in the state changes.

The prefix preserves every earlier character, including requests that introduce an antecedent. It removes the line break and all text following the queried sentence. No reference subject, rewritten claim or proposed binding enters either subject request.

Three rounds use 972 subject calls: full and prefix for every claim. Another 162 calls ask the unchanged six numerical verdict questions under clean and deliberately swapped proposals, regardless of subject results. The budget is 1,134 calls and 1,944 answers.

## Display and scoring

Each subject reply supports both clean and swapped comparisons. Code compares the selected service with the supplied proposal; it never changes that proposal or the numerical verdict request. Display still requires matching service and both selected probabilities at or above 0.70. Missing answers and sentence quarantines withhold guidance.

The assessment counts each actual subject reply once for unique service accuracy. Both proposal conditions retain full denominators for safe and unsafe displays, withholding and original-verdict accuracy. Paired service and display gains and losses compare prefix with fresh full-note calls by application, wording and round.

The prefix candidate must resolve every subject, preserve correct clean baseline displays with at least 90% coverage and display no unsafe swapped guidance in every panel and round. The full-note comparator cannot replace it after inspection. Actual call costs remain separate from overlapping composed-workflow totals.

## Limits

The same assistant wrote and inspected these notes and references. Human and independent reviews remain zero. Every tested claim has a uniquely resolvable earlier subject; future-dependent and genuinely unresolved reports remain untested. Repeated calls are not independent incidents. No protected recordings open.
